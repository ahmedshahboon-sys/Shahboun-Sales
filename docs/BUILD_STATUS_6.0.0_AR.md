# Shahboun Suite 6.0.0 — حالة البناء

## مكتمل
- توحيد رقم الإصدار 6.0.0 في Android Sales + Licensing + Windows/Web.
- اعتماد أصل لوجو موحد وضغط أصول الصور لتقليل الحجم.
- تنظيف ملفات ترقيات وتقارير قديمة من توزيع Web/Windows.
- إضافة تعريف مركزي للإصدار ومعلومات Suite.
- تحديث طلب التفعيل في Android ليشمل الإصدار والمنصة والمتجر والمالك والهاتف ومعرف الجهاز.
- تحديث Web لتجهيز رسالة واتساب تشمل الإصدار والمنصة وكود طلب الترخيص.
- تجهيز Windows Setup 6.0.0 ليعتمد على Runtime مضمّن بدل مطالبة العميل بتثبيت أدوات البرمجة يدويًا.
- تحديث First Run ليعمل Production ويمنع التثبيت الناقص.
- فحص Syntax لملفات JS/CJS ناجح (157 ملفًا).
- فحص Parsing لملفات TS/TSX ناجح (28 ملفًا).

## قيد التنفيذ
- Android Host Server الحقيقي للدخول عبر LAN.
- توحيد بروتوكول توقيع الترخيص بين Windows Host وAndroid Host بالكامل.
- بناء APKs الموقعة وWindows Setup النهائي.

## قاعدة المشروع
هذا الفرع `suite-6.0.0` هو خط التطوير الرسمي الجديد. أي تعديل وظيفي عام يجب تطبيقه على Android وWeb معًا، باستثناء خصائص المنصة الخاصة مثل كاميرا Android أو خدمات Windows.
